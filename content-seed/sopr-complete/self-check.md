Закрепим три действия: описать рельеф, оценить глубину дефекта, выбрать подход к уточнению изменений. Случаи ниже учебные.

## Разберите признаки
На слизистой есть участок другого цвета. Ткань непрерывная, рельеф прежний. По этому описанию элемент — [[пятно|папула|язва]].

В другом случае видно небольшое возвышение с жидкостью. После разрыва покрышки остаётся поверхностный дефект. Исходный элемент — пузырёк, вторичный — [[эрозия|узел|пятно]].

Если дефект достигает соединительной ткани и после заживления образуется рубец, по глубине это язва. Название элемента остаётся морфологическим описанием; установить причину только по этой схеме нельзя.

## Свяжите описание и метод
Для ответа о клеточном составе обращаются к [[цитологическому исследованию|определению названия по рельефу|фотосъёмке как единственному методу]]. Для строения ткани рассматривают гистологию. При обоих подходах результаты сопоставляют с анамнезом и объективным осмотром.

Выполните итоговый тест, затем вернитесь к соответствующему уроку, если требуется повторить признак.
