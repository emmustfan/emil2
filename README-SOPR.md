# Интерактивный курс по СОПР в локальном preview

Основа этой ветки — этап 16. В ZIP входят платформа, полный оригинал пособия КФУ (54 страницы) и десять уроков с иллюстрациями. В каждом уроке три пропуска и пять тестовых вопросов с пояснениями. Главы собраны по темам. Ссылки на страницы вынесены в источники.

Пошаговый сценарий для выступающей на MacBook находится в [памятке HTML](docs/presentation-mvp.html) внутри ZIP. Откройте файл в обычном браузере. В памятке установка Docker Desktop, вход через Mailpit, аккаунты, сценарий показа и приглашение в группу.

## Запуск на Mac

Остановите уже запущенную preview-версию платформы, если она занимает порты
3000 и 8025. Распакуйте этот архив в «Загрузки» и откройте Docker Desktop.

```bash
cd ~/Downloads/emil2-codex-sopr-complete-preview && bash start-mac.command
```

Войдите под `owner@example.ru`. Письмо для входа придёт в
[Mailpit](http://localhost:8025). После входа откройте
[полную методичку](http://localhost:3000/admin/subjects/preview-sopr-complete).
Для показа вопросов и проверки ответов откройте
[предпросмотр ученика](http://localhost:3000/admin/topics/preview-sopr-complete-demo/student-preview).

Материал добавляется в preview как черновик. При переходе со старой сборки обновляются исходные демоглавы. Ручные правки и опубликованные темы сохраняются. После обновления повторный запуск использует существующий курс. Для просмотра и редактирования откройте «Книгу и редактор уроков» на странице предмета. Источник хранится в корне
архива в файле `Metodichka_Khafizova_SOPR.pdf`.

## Источник и подготовка

Р. Г. Хафизов, Ф. А. Хафизова, Н. В. Малышев, А. Р. Фасахов.
Патоморфологические процессы и элементы поражения при заболеваниях слизистой
оболочки полости рта. Казань, Издательство Казанского университета, 2019.
54 с.

Уроки переработаны для обучения. В них тематические разделы, иллюстрации,
пропуски и тесты. Оригинал пособия в корне архива сохранён без изменений.
