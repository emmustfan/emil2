# Интерактивный курс по СОПР в локальном preview

Основа этой ветки — этап 16. В ZIP входят платформа, полный оригинал пособия КФУ (54 страницы) и девять уроков с иллюстрациями. В каждом уроке три пропуска и пять тестовых вопросов с пояснениями. Главы собраны по темам. Ссылки на страницы вынесены в источники.

Пошаговый сценарий для выступающей на MacBook находится в [памятке HTML](docs/presentation-mvp.html) внутри ZIP. Откройте файл в обычном браузере. В памятке установка Docker Desktop, вход через Mailpit, аккаунты, сценарий показа и приглашение в группу.

## Запуск на Mac

Остановите уже запущенную preview-версию платформы, если она занимает порты
3000 и 8025. Распакуйте этот архив в «Загрузки» и откройте Docker Desktop.

```bash
cd ~/Downloads/emil2-codex-sopr-complete-preview && bash start-mac.command
```

Войдите под `demo-student-01@example.ru` через [Mailpit](http://localhost:8025).
После входа откройте [курс СОПР](http://localhost:3000/subjects/sopr-khafizov-complete)
или [урок о первичных элементах](http://localhost:3000/learn/sopr-khafizov-complete/primary-lesions).
Задания доступны бесплатно. Учебная адаптация пока ожидает экспертной проверки.

Войдите под `owner@example.ru`, чтобы открыть [редактор курса](http://localhost:3000/admin/subjects/preview-sopr-complete/editor).
В локальной сборке сохранённый урок опубликованного предмета можно открыть студентам кнопкой «Опубликовать».
Кнопка «В архив» убирает урок из списка и сохраняет связанные данные.
Восстановление доступно в разделе «Архив уроков» на странице предмета.
При обновлении исходные демоглавы публикуются автоматически. Ручные версии сохраняются.

Р. Г. Хафизов, Ф. А. Хафизова, Н. В. Малышев, А. Р. Фасахов.
Патоморфологические процессы и элементы поражения при заболеваниях слизистой
оболочки полости рта. Казань, Издательство Казанского университета, 2019.
54 с.

Уроки переработаны для обучения. В них тематические разделы, иллюстрации,
пропуски и тесты. Оригинал пособия в корне архива сохранён без изменений.
