# Полная методичка по СОПР в локальном preview

Основа этой ветки — этап 16 на коммите `49113a1`. В архив входят платформа, исходный PDF и материалы для
автоматической загрузки в preview. После запуска появятся десять глав,
охватывающих страницы 1–54, и отдельный интерактивный пробный урок.
В главах сохранены 22 рисунка и схемы, вопросы для самоконтроля и литература.
В пробном уроке — пять из этих иллюстраций, три пропуска и пять вопросов
с объяснениями.

## Запуск на Mac

Остановите уже запущенную preview-версию платформы, если она занимает порты
3000 и 8025. Распакуйте этот архив в «Загрузки» и откройте Docker Desktop.

```bash
cd ~/Downloads/emil2-codex-sopr-complete-preview && bash start-mac.command
```

Войдите под `owner@example.ru`. Письмо для входа придёт в
[Mailpit](http://localhost:8025). После входа откройте
[полную методичку](http://localhost:3000/admin/subjects/preview-sopr-complete).
Для показа вопросов и проверки ответов откройте
[предпросмотр ученика](http://localhost:3000/admin/topics/preview-sopr-complete-demo/student-preview).

Материал добавляется в preview как черновик. Повторный запуск использует уже
загруженные главы и сохраняет внесённые правки. Для редактирования откройте
«Книгу и редактор уроков» на странице предмета. Источник хранится в корне
архива в файле `Metodichka_Khafizova_SOPR.pdf`.

## Источник и подготовка

Р. Г. Хафизов, Ф. А. Хафизова, Н. В. Малышев, А. Р. Фасахов.
Патоморфологические процессы и элементы поражения при заболеваниях слизистой
оболочки полости рта. Казань, Издательство Казанского университета, 2019.
54 с.

Границы страниц подписаны в каждой главе. При переносе убраны типографские
переносы строк и слов. Табличные задания сохранены с исходным расположением
колонок, схемы помещены рядом с подписями. PDF сохранён без изменений.
