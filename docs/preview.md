# Временный тестовый просмотр

Пользователь 7 ноября 2026 разрешил отдельную тестовую ссылку для просмотра.
Облачная конфигурация не изменялась и не публиковалась. Рабочий `.env`, база
и основные контейнеры проекта сохранены.

Для просмотра создана отдельная база `dental_preview_*` с отдельной ролью
PostgreSQL (без SUPERUSER/CREATEDB/CREATEROLE). Применены миграции и seed,
добавлен немедицинский предмет «Попробуйте платформу»: бесплатный урок с
10 пропусками и 5 вопросами, соседняя закрытая тема. Медицинские seed-темы
остались черновиками.

Подготовка данных:

```sh
corepack pnpm exec tsx scripts/preview/prepare.ts
corepack pnpm exec tsx scripts/preview/initialize.ts
```

Конфигурация с новым паролем БД сохраняется только в игнорируемом
`tmp/preview/database.json` с mode 0600. Скрипт seed отказывается работать
с базой без строго заданного префикса и случайного суффикса. Повторная подготовка
сохраняет существующую конфигурацию и ответы.

Просмотр работает отдельным контейнером `dental-learning-preview`, локальный
порт 3200. Образ `dental-learning-preview-web` содержит предварительно собранный
интерфейс (`pnpm build` → `pnpm start`), без dev-сервера и HMR. Runtime
`NODE_ENV=development` позволяет использовать mock/log/local только в этом
изолированном тестовом запуске; существующая проверка production-конфигурации
и основной Dockerfile не ослаблялись. Это временный стенд, не боевой деплой.

Внешний HTTPS/WebSocket-канал использует Tunnelmole через штатный HTTPS_PROXY,
TLS verification включена. Инструменты `ws` и `https-proxy-agent` установлены
только в игнорируемую папку `tmp/preview-tools`; зависимости проекта не менялись.
Временный relay и его состояние находятся в `tmp/preview/`. Он передаёт запросы
только к локальному порту 3200 и разрешённым страницам каталога/уроков,
статическим ресурсам и API ответов. Вход, админка, профиль и оплата закрыты
на внешнем входе. Для урока регистрация не нужна. `robots.txt` запрещает обход,
ответы содержат X-Robots-Tag noindex/nofollow/noarchive.

Актуальный внешний адрес — в `tmp/preview/address.json`. Он временный:
остановка среды или канала делает ссылку недоступной. Постоянный хостинг и домен
не создавались. Остановить сайт можно командой `docker stop dental-learning-preview`;
рабочие контейнеры эта команда не затрагивает. Базу с результатами автоматически
не удаляем.

- Внешние `/subjects`, бесплатный и закрытый уроки — HTTP 200.
- `/admin` и `/api/auth/email` снаружи — 403, robots.txt — запрет обхода.
- В настоящем Chromium через публичный HTTPS-адрес: 10 ответов на пропуски
  (включая ошибку), тест из 5 вопросов, восстановление незавершённого теста
  и итогового прогресса после перезагрузки. Cookie Secure/HttpOnly подтверждена.
- На мобильном размере 390 px проверены переход из каталога, открытие урока,
  наличие всех 10 пропусков и отсутствие горизонтального скролла.
- Lint, typecheck, 53 unit-теста — успешно; отдельная сборка preview-образа успешна.

  `tmp/screenshots/preview-public-mobile.png`.
