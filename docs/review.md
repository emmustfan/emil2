# Как проверить повторение

1. Запустите свежую версию проекта на Mac: `bash start-mac.command`.
2. Сначала войдите через `/login`. Для локального просмотра можно использовать
   `owner@example.ru`; письмо откроется в Mailpit на http://localhost:8025.
   Ссылку из письма открывайте в том же браузере. При первом входе заполните профиль.
3. Откройте «Предметы» → «Попробуйте платформу» → любую бесплатную тему.
   Ответьте на несколько пропусков, хотя бы один раз ошибитесь. Начните тест
   и тоже дайте неверный ответ.
4. Откройте «К повторению» в шапке или http://localhost:3000/review.
   Карточки из ошибок появятся сразу. Правильно заполненный пропуск тоже создаёт
   карточку, но она придёт через день. Старые ответы после обновления проекта
   автоматически становятся карточками с исходной датой ответа.
5. Попытайтесь вспомнить ответ и нажмите «Показать ответ». Для нескольких
   правильных вариантов показывается весь набор, для текстового задания — эталон
   и заданные автором допустимые формулировки. Есть объяснение и ссылка на урок.
6. Оцените, насколько легко вспомнили: «Сложно» — через 10 минут, «Норм» — через
   день, «Легко» — через 3 дня для новой карточки. При следующих повторениях
   интервалы растут; фактический интервал указан на каждой кнопке.
7. Когда очередь закончится, увидите число повторений за день и дату следующих
   карточек. Через 10 минут после «Сложно» обновите страницу или нажмите
   «Проверить очередь» — карточка вернётся.

Клавиши: пробел открывает ответ, 1 / 2 / 3 сохраняют соответствующую оценку.
В уроке используются радиокнопки, чекбоксы и ввод; в повторении нужно вспомнить
ответ и оценить себя после проверки.

Новых карточек — до 30 в день; уже начатые повторения этот лимит не расходуют.
Лимит считается при первом показе ответа по часовому поясу профиля. Даты
следующих повторений отображаются в том же часовом поясе. Все параметры
расписания хранятся в `AppSetting`.

Для личной очереди проходите урок после входа. Ответы гостя сохраняются отдельно;
их перенос при регистрации появится с демо-воронкой на этапе 6. Повторение
показывает только опубликованные материалы, к которым у аккаунта есть доступ.
Карточки закрытого предмета сохраняются при окончании доступа и снова появляются
после его восстановления. Архивные задания не показываются.
