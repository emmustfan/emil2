# Доработка создания и проверки уроков

Приоритет уточнён обратной связью: редактор и качество проверки уроков перед
автоматическим импортом. Включён узкий P1 изображений в методичке. Парольный
вход, OCR, видео, автоматическая ИИ-рецензия и генерация уроков не добавлялись.
Медицинские seed-черновики не публиковались; реальные внешние сервисы не вызывались.

## Что проверено

- `lint`, `typecheck`, `format:check`, `git diff --check`, сборка Next.js.
- **140 unit-тестов**: безопасные ссылки изображений, подписи и разметка,
  нормализация WebP, пределы размера/пикселей, удаление метаданных, подделка
  формата, chunked upload без Content-Length, список готовности, шаблон
  ИИ-рецензии без профиля/приватных URL, статусы интеграций без секретов.
- **108 интеграционных тестов**, включая 6 новых сценариев изображений:
  роли и назначения; черновик/опубликованный бесплатный урок; платный доступ
  и отзыв; чужие/несуществующие изображения при публикации; снятие назначения;
  удаление файла только после успешного удаления темы.
- **76 E2E-сценариев** на desktop/mobile Chromium. Новые сценарии проходят
  загрузку картинки, предпросмотр, отметку рецензента, публикацию и просмотр
  гостем, готовый запрос ИИ и страницу интеграций. Проверены запреты для ученика,
  учителя в общих интеграциях и запроса с чужим Origin. Прежние сценарии
  редактора и идентичность заданий также прошли.

Первый новый браузерный тест ожидал сокращённую надпись кнопки «На проверку»;
локатор исправлен на фактическую «Отправить на проверку». Это не меняло
поведение публикации. После исправления новые сценарии и общий набор прошли.

## Mac / Docker

Полный `.env.example` передан migrate/web/worker через env_file в отдельном
Compose-проекте с прежними preview-томами. Применены 14 миграций, включая
добавочную TopicImage, без сброса данных; web/worker запущены.
Проверена именно библиотека обработки изображений внутри Docker.

На синтетическом немедицинском уроке браузер загрузил PNG, получил WebP,
показал картинку в редакторе и после публикации — гостю. После пересоздания
web-контейнера сохранность байтов изображения проверена по SHA-256.
Файл удалён через штатное удаление тестовой темы; остальные проверочные
записи удалены. Снимок до/после подтвердил сохранение прежних пользователей,
ролей, уроков, ответов, прогресса, подписок, платежей, настроек и документов.

Опциональный `docker-compose.integrations.yml` проверен только командой
`config` с фиктивными ключами. Он меняет выбор LLM/Telegram, сохраняя ту же
preview-базу/тома, mock-платежи, Mailpit и local. Реальные API не вызывались.
Обычный `start-mac.command` по-прежнему оставляет моки.

Артефакты в игнорируемом `tmp/screenshots/`: `authoring-editor-chromium.png`,
`authoring-editor-mobile.png`, `authoring-docker-desktop.png`,
`authoring-integrations-mobile.png`. Физический Mac проверяется пользователем.

## Границы

Новая прямая зависимость — `sharp@0.35.5`, та же версия, которая уже была
транзитивно у Next.js: нужна для декодирования растров, удаления метаданных,
ограничения размеров и единого WebP. Не полагаемся на скрытую зависимость Next.

Изображения сейчас работают с local в Docker-томе разработки. Рабочий S3-адаптер
ещё не реализован; перед production нужен перенос файлов в хранилище проекта.
Удалённые из Markdown картинки остаются среди загрузок темы и учитываются
в лимите. Нет управления библиотекой медиа, анализа картинок моделью или
вставки изображений в варианты вопросов.

Запрос рецензии копируется вручную: внешнего ИИ-вызова, автоматической
экспертной отметки и изменения юридических документов нет. Интеграции
показывают наличие настроек, а не подтверждённое соединение. Конкретный
провайдер и ключи владельцем пока не заданы в этой среде.

Инструкции: [создание урока](lesson-authoring.md), [подключение сервисов](integrations.md).
