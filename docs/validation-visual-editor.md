# Визуальный редактор, пропуски и тьютор

Запрос владельца: форматировать выделенный текст кнопками, выбирать слова
внутри предложений и задавать вопросы тьютору в правой панели во время чтения.

## Поведение

- Tiptap 3.33.1: заголовок, жирный, курсив, подчёркивание, цитата, список,
  таблица, отмена и повтор; изображения через прежнюю загрузку урока.
- Выделение слова → «Пропуск» → варианты и объяснение → сохранение на месте.
  Цветная метка выбирается повторно для изменения задания.
- Один вариант и короткий ответ отображаются в тексте, множественный выбор —
  чекбоксами после абзаца; итоговый тест сохраняет отдельные карточки.
- Выбор варианта не отправляет попытку: нужна галочка проверки. Первые ответы,
  тренировка, прогресс и карточки повторения используют прежние серверные API.
- Один тьютор справа на компьютере. На телефоне — раскрываемая панель с тем
  же диалогом; после перезагрузки страницы панель открывается кнопкой снова.

## Проверки

- 162 модульных теста, включая обратимость форматирования, таблиц и изображений,
  сохранение ключей пропусков, безопасное подчёркивание и запрет внешних картинок.
- 121 интеграционный тест прошёл после браузерных проверок.
- Браузерный набор содержит 88 сценариев (44 desktop + 44 mobile Chromium).
  После полного прогона целевые сценарии редактора и тьютора повторялись
  после исправлений. Проверены создание/изменение пропуска, форматирование,
  повторное открытие, вставка изображения, публикация, типы заданий, конфликт
  двух окон с сохранением локального текста, quota и защита тьютора.
- Для проверки конфликта используется основной визуальный редактор. Текст
  сравнивается через innerText, поскольку абзацы — отдельные элементы DOM.
  Подтверждено, что локальный текст остаётся, а сохранённая версия не меняется.
- `lint`, `typecheck`, `format:check`, `git diff --check` и рабочая Docker/Next
  сборка. Новые зависимости закреплены; дополнительные сервисы не нужны.

Первичная браузерная проверка выявила: вставку inline-изображения в схему
документа, лишнее событие изменения при readonly, конфликт транзакции при
вставке на мобильном и нестабильное раскрытие исходника. Изображения сделаны
блочными, синхронизация внешнего содержимого и команды вставки исправлены,
readonly не помечает текст изменённым; исходник открывается управляемой кнопкой.
Правильные ответы по-прежнему не выдаются ученику заранее. Подчёркивание
поддержано без включения произвольного HTML. Медицинские seed-черновики
не публиковались; реальные модели и платежи не вызывались.

Схема БД и формат старых уроков сохранены. Инструкция автору —
[lesson-authoring.md](lesson-authoring.md), пример экрана —
[redesign.md](redesign.md). Это локальное обновление, сайт не развёртывался.
