# Прогресс студента: что видно администратору

В этапе 12А доступ есть только у администратора. Учитель, ученик и гость
получают 404 на страницах и API этого раздела, в том числе при попытке открыть
собственную карточку через административный адрес.

## Открыть сводку

1. Войдите администратором и выберите слева **«Прогресс студентов»**.
2. Найдите ученика по имени или email. В списке только пользователи с ролью
   «Ученик», которые не удалены; заблокированные ученики остаются в истории.
3. Выберите **«Отстающие»**, чтобы увидеть тех, кто завершил меньше заданного
   процента тем по предметам с активностью **или** не занимался больше
   заданного числа дней. По умолчанию это 50% и 7 дней. Пороги и размер
   страницы меняются в «Настройки».
4. Нажмите заголовок столбца, чтобы изменить сортировку; повторное нажатие
   меняет направление. Доступны все столбцы, включая предметы и даты.
5. Нажмите имя ученика. Ссылка **«Прогресс и ответы»** также есть в списке
   пользователей и в карточке пользователя.

«Средний балл» — среднее лучших результатов тестов по изученным опубликованным
и проверенным темам. Это тот же принцип, что в собственном кабинете ученика.
В знаменателе завершения — опубликованные проверенные темы предметов,
по которым у ученика уже есть активность. Темы, с которыми он ещё не
знакомился в других предметах, автоматически в знаменатель не добавляются.

## Карточка ученика

Сверху можно выбрать один предмет или все предметы. Каждый успешный запрос
карточки записывается в журнал: кто посмотрел, какого ученика, какой предмет
и когда. При просмотре всех предметов предмет в записи не указан. Ссылки
на карточки не загружают данные заранее при наведении.

В карточке находятся:

- завершённые темы, средний балл и последняя активность;
- по каждой теме — первый ответ на каждый пропуск, текущий правильный ответ,
  все сохранённые попытки с датами и отметкой «Практика»;
- все прогоны теста, баллы, продолжительность, ответы ученика и эталоны;
- количество карточек всего, к повторению и просроченных;
- распределение оценок «Сложно / Нормально / Легко» за последние 30 календарных
  дней с подписью **«Самооценка студента»**;
- полоса активности за 30 дней: открытия уроков, ответы на пропуски,
  старты тестов, ответы в тестах, оценки карточек и вопросы тьютору;
- только количество вопросов тьютору, по темам. **Переписка не показывается.**

«К повторению» включает доступные карточки, срок которых уже наступил,
без суточного ограничения на новые карточки. «Просрочено» — те из них,
которые нужно было повторить до начала сегодняшнего дня по времени ученика.
Время попыток в карточке показывается в часовом поясе администратора;
дни полосы активности — UTC.

У ответов к другой опубликованной версии есть пометка **«Ответ к версии N»**.
Эталон восстанавливается из сохранённого снимка публикации. Если старый
снимок отсутствует, вместо предполагаемого старого эталона показано
«Эталон прежней версии недоступен». Первый ответ и его оценка остаются
неизменными при тренировке и публикации новых формулировок.

Удалённый ученик отображается как **«Удалённый пользователь»**, без имени
и контактов. После штатной анонимизации подробная история ответов удаляется
вместе с остальными учебными данными; запись просмотра остаётся в журнале.

## Что видит ученик

В открытом уроке авторизованный ученик раскрывает **«История ответов»**.
Там только его попытки по пропускам, включая практику, время, результат
и номер версии. История не раскрывает эталоны ещё не отвеченных заданий.
Гостевые ответы в новый журнал всех попыток не записываются; прежнее
сохранение первого гостевого ответа продолжает работать.

При обновлении старые первые ответы авторизованных пользователей копируются
в журнал с прежними датами. Историческую версию, которую система раньше
не сохраняла, восстановить нельзя: для переноса используется текущая версия
темы. Остальные прежние ответы, результаты, карточки и платежи сохраняются.

## Демо на Mac

После `bash start-mac.command` в preview появляются 12 вымышленных учеников.
Их имена начинаются с «Демо» и заканчиваются «(демо)», email —
`demo-student-01@example.ru` … `demo-student-12@example.ru`.

Есть два отличника, четыре средних ученика, два отстающих, два давно
не занимавшихся, один новичок и один ученик с повторными ошибками в практике.
История распределена по последним 30 дням и создаётся настоящими сервисами
обучения. Для платных уроков выдан ручной доступ с причиной «демо».

Первые три аккаунта готовы к входу через Mailpit. Например, откройте отдельный
браузер, запросите вход для `demo-student-01@example.ru` и откройте письмо
в http://localhost:8025 в том же браузере, где начинали вход.

В демо есть отдельная опубликованная preview-копия стоматологического урока.
Она явно помечена как непроверенный медицинский пример, не получает
экспертного подтверждения и не входит в оценочные итоги кабинета.
Исходный авторский стоматологический черновик сохраняется. Такая копия
и демо-ученики создаются только на preview-базе, вне production; обычный
`pnpm db:seed` их не создаёт.

Повторный запуск сохраняет ручные изменения имени, email, ролей и учебных
данных: ученик с любой существующей активностью пропускается. Если первый
запуск был прерван посреди ученика, уже созданная активность также сохраняется
и не переписывается автоматически.

## Что добавит этап 16

Будут доступны журнал учебной группы, предметные права её преподавателя,
сводный анализ заданий, видео и экспорт. Эта карточка и журнал попыток будут
переиспользованы. Вход администратора под пользователем относится к отдельному
этапу 12Б; в 12А такого входа нет.
