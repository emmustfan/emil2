# Книга уроков и подготовка запуска на домене

Проверка обновления редактора по HTML-прототипу: разделы и уроки создаются
в книге, материал и «Как увидит студент» находятся рядом, тест и проверка
публикации — ниже. Схема БД, форматы уроков и серверные API сохранены.

## Подтверждённые проверки

- `pnpm lint`, `pnpm typecheck`, `pnpm format:check`, `git diff --check`.
- 162 модульных теста — успешно.
- 121 интеграционный тест — успешно.
- **90 браузерных сценариев** — полный успешный прогон: 45 на компьютере
  и 45 в мобильном Chromium.
- Production-образ `Dockerfile.production --target production` собран:
  Next.js компиляция, TypeScript и генерация страниц завершились успешно.
- Синтаксис production Compose проверен с синтетическим env-файлом;
  рабочий `.env.production` не создавался и сервисы сайта не запускались.
- Команда `preflight` из инструкции выполнена внутри собранного образа
  с синтетическими параметрами и отключённой сетью: результат
  `production_configuration_valid`. Проверка не обращалась к поставщикам.

Новый браузерный сценарий проверяет, что учитель создаёт раздел, затем урок
в нём, переключается между уроками и возвращается к сохранённым правкам.
Созданный урок остаётся черновиком; URL соответствует выбранному уроку.
Также проверено отсутствие горизонтальной прокрутки на узком экране.

Существующие сценарии проверяют изображения и предпросмотр, три типа ответов,
создание и редактирование пропусков, тест, экспертную проверку, публикацию,
конфликт двух редакторов, отзыв доступа учителя и запрет ученического доступа
к управлению. Выбор слов, урок, прогресс и тьютор продолжают использовать
прежние защищённые маршруты. Селекторы тестов обновлены для карточек вопросов
и фактического названия урока в заголовке.

Раннее нажатие переключателя исходника до подключения React могло теряться.
Переключатель теперь доступен после подключения обработчика. Сценарий
редактирования вопросов, добавления пропуска и публикации повторён дважды
на каждом размере экрана, затем прошёл в полном наборе.

## Инструкции владельцу

- [Создание урока](lesson-authoring.md): книга, новые разделы/уроки,
  сохранение при переключении, бесплатные материалы и диагностика.
- [Размещение study.shkolaru.ru](launch-shkolaru.md): новый Ubuntu VPS,
  DNS, Docker, HTTPS, запуск, обновление, копии и диагностика ошибок.
- [Интеграции на сервере](integrations-production.md): SMTP, модели чата
  и embeddings, закрытые S3-бакеты, тестовая ЮKassa, Telegram и аналитика.
  Ссылки добавлены в README и админку интеграций.

Все браузерные и интеграционные проверки использовали тестовые адаптеры,
локальную базу и фикстуры. DNS, VPS, реальные модели, письма и платежи
не подключались; медицинские черновики не публиковались. Реальную доставку
почты, API выбранных поставщиков, тестовый магазин и восстановление копии
нужно проверить на выбранном сервере по указанным инструкциям.
