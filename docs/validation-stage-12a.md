## Миграция с данными

На наполненной локальной базе после этапа 12 запущен
`node scripts/ops/check-stage12a-migration.mjs`. Скрипт добавляет собственные
фикстуры в транзакции, применяет SQL и **всегда делает ROLLBACK**.
Два первых ответа принадлежат зарегистрированному пользователю (выбор и
текст), один — гостю. Существуют карточка и связанные тема/пропуски.

| Показатель                   | До SQL | После SQL |
| ---------------------------- | -----: | --------: |
| GapAnswer                    |      3 |         3 |
| Card                         |      1 |         1 |
| Авторизованные первые ответы |      2 |         2 |
| GapAttempt                   |      0 |         2 |
| Гостевые GapAttempt          |      0 |         0 |

Сверены время, оценка, версия темы, признак практики и выбранные значения.
Остальные проверенные таблицы (QuestionAttempt, TopicProgress, Payment)
не изменились. После отката обычный `pnpm db:migrate` применил миграцию
к рабочей локальной базе; сброса и удаления томов не было.

через настоящие сервисы, исходный стоматологический черновик сохранён.

Фактический диапазон баллов средних профилей — **60–80%**, включая тест из
шести вопросов. Есть 18 дополнительных тренировочных попыток.

`tests/integration/preview-students.test.ts` самостоятельно создаёт отдельную
случайную preview-базу, выполняет штатную подготовку и проверяет:

- ровно 12 профилей с активностью, согласия первых трёх, практику, повторение
  и ручные доступы с причиной «демо»;
- непроверенную опубликованную preview-копию стоматологического урока и
  сохранение исходного авторского DRAFT;
- сохранение ручной смены имени **и email**: хеши 17 таблиц до и после
  повторного запуска полностью совпадают;
- отказ в production и на обычной базе до записи данных;
- диапазоны фактических баллов и бюджет производительности.

После теста удаляется только созданная им временная база. Для этого тестовый
пользователь PostgreSQL должен иметь CREATEDB; штатный PostgreSQL тестового
Compose и CI это позволяет. В существующих базах ничего не сбрасывается.
