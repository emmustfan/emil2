# Видеолекции Rutube

## Добавление в урок

1. Откройте редактор урока и в разделе **Видео** нажмите **Добавить видео**. Укажите название, ссылку или код iframe и при наличии длительность в формате `мм:сс` или `чч:мм:сс`.
2. Подтвердите, что в видео отсутствуют персональные данные пациентов либо есть письменное согласие. Видео доступно всем, у кого есть ссылка. Платформа проверяет доступ к уроку перед передачей URL плеера браузеру.
3. Сохраните видео. В тексте появится отдельный блок `::video{#uuid}`. В форме вопроса включите **Показать в видео** и укажите время. Опубликуйте текст и вопросы обычным порядком.
4. Кнопка **Изменить ссылку** заменяет источник опубликованного видео сразу. Для другой лекции создайте новый блок. Чтобы архивировать старый блок, удалите его из черновика вместе с его вопросами и опубликуйте изменения.

Поддерживаются следующие адреса на `https://rutube.ru`.

- `/video/<id>/`
- `/video/private/<id>/?p=<key>`
- `/play/embed/<id>/` и `/play/embed/<id>/?p=<key>`
- HTML-код iframe с одним таким адресом в `src`

ID содержит 32 строчные шестнадцатеричные цифры. Ключ `p` состоит из 1–128 латинских букв, цифр, дефисов или подчёркиваний. Параметры вроде `r` и `t` отбрасываются. Вставляйте адрес через форму **Видео**. Текст и снимки урока хранят внутренний UUID.

## Просмотр и вопросы

Плеер отправляет просмотренные интервалы каждые 15 секунд, на паузе и при скрытии или закрытии страницы. Сервер объединяет пересечения и считает длительность уникальных интервалов. Порог по умолчанию равен 90%. Скачок позиции сам по себе просмотром не считается. Это учёт учебной активности. Клиентские сообщения и самоотметки могут быть недостоверными.

При пересечении времени вопроса плеер получает команду паузы. Вопрос также можно открыть вручную под плеером. Правильный ответ и объяснение появляются после отправки. Разбор сохраняется в прогоне `VIDEO`, ошибка добавляет карточку повторения.

Без известной длительности кнопка **Я посмотрел лекцию** доступна сразу. Если после загрузки iframe десять секунд нет распознанных сообщений о состоянии и позиции, кнопка становится доступна и при известной длительности. Гости могут смотреть общедоступное видео. Для записи просмотра и ответов нужен аккаунт. Преподаватель группы видит пометку «просмотр отмечен студентом» в составе группы по своим предметам.

## Протокол и ручная проверка

**Не проверено на живом плеере.** Имена сверены 20 ноября 2026 года с неофициальным описанием Rutube Player API. Приложение принимает сообщения только от iframe на `https://rutube.ru`. В CSP этот адрес разрешён как источник iframe. Фактические домены и совместимость нужно проверить на реальном видео. [Неофициальное описание Rutube Player API](https://github.com/evikza/Rutube-Player-JS-API-Doc)

| Направление  | Тип                           | Данные                                                    |
| ------------ | ----------------------------- | --------------------------------------------------------- |
| Плеер → урок | `player:ready`                | Готовность                                                |
| Плеер → урок | `player:changeState`          | `data.state`, в том числе `playing`, `pause` или `paused` |
| Плеер → урок | `player:currentTime`          | `data.time` в секундах                                    |
| Урок → плеер | `player:setCurrentTime`       | `data.time` в секундах                                    |
| Урок → плеер | `player:pause`, `player:play` | Пустой объект                                             |

1. Под `student@example.ru` откройте `http://localhost:3000/learn/platform-demo/test-video-lecture`. На реальном публичном видео проверьте воспроизведение и демо-вопросы на 0:30 и 1:00. Затем под `owner@example.ru` добавьте закрытую ссылку в платный тестовый урок и выдайте доступ отдельному тестовому студенту. Почта для входа доступна на `http://localhost:8025`.
2. Прокрутите страницу до iframe, откройте Console в DevTools и выполните код. Он повторно загружает iframe и выводит только имя события, состояние и время.

```js
(() => {
  const frame = [...document.querySelectorAll("iframe")].find((item) =>
    item.src.startsWith("https://rutube.ru/play/embed/"),
  );
  if (!frame) return;
  window.addEventListener("message", (event) => {
    if (
      event.origin !== "https://rutube.ru" ||
      event.source !== frame.contentWindow
    )
      return;
    try {
      const msg =
        typeof event.data === "string" ? JSON.parse(event.data) : event.data;
      if (msg?.type === "player:ready") console.info(msg.type);
      if (msg?.type === "player:changeState")
        console.info(msg.type, msg.data?.state);
      if (msg?.type === "player:currentTime")
        console.info(msg.type, msg.data?.time);
    } catch {}
  });
  frame.setAttribute("src", frame.getAttribute("src"));
})();
```

3. Дождитесь `player:ready`, включите воспроизведение и проверьте `player:changeState` со значением `playing` и увеличивающиеся значения `player:currentTime`. У вопроса должно появиться состояние паузы. Ответьте, нажмите **Продолжить** и проверьте новое `playing`. Нажмите **Перейти к моменту** и проверьте новое значение времени. Повторите в Chrome и мобильном Safari, включая вход и выход из полноэкранного режима.
4. Если вопрос появляется, а видео продолжает играть, поставьте его на паузу кнопкой самого плеера. Откройте вопрос из списка под видео. Если события не распознаются, используйте **Я посмотрел лекцию**. Запишите версию браузера и безопасные имена событий из Console. В Network проверьте домен iframe и наличие ошибок CSP. При отправке скриншота оставьте только элементы интерфейса и имена событий.

E2E перехватывает iframe в Playwright и использует тот же адаптер. Веб-приложение загружает обычный адрес плеера.

## Черновик заданий

В карточке видео откройте **Сгенерировать задания** и загрузите VTT, SRT, текстовый TXT, DOCX или PDF с текстовым слоем. Подтвердите права на исходник. Источник с метками времени даёт вопросы в видео и тест. У документа без меток времени можно проверить конспект и тестовые вопросы, а нужные моменты видео расставить в редакторе.

Расход ИИ учитывается в `LlmUsage`. Новая генерация останавливается, если расчётный расход достиг дневного бюджета. Очередь импорта показывает, сколько заданий принято и сколько отброшено по формату, цитате, времени или лимиту. Проверьте конспект и задания в черновике. Для сопоставления с источником используйте цитату и ссылку на момент в предпросмотре. Публикация требует редакторской проверки. Исходник удаляется после обработки.
