## Что подтверждено

- Каталог и страница предмета показывают только опубликованные объекты,
  фильтр курса, разделы, количество тем/пропусков/вопросов, вход в бесплатную тему.
- Гость проходит бесплатный урок целиком: пропуски, тест, итог. Первый пропуск
  заполнен стрелками и Enter; проверены HttpOnly/SameSite cookie и отсутствие
  горизонтального скролла на desktop/mobile.
- После перезагрузки сохраняются ответы на пропуски, частично пройденный тест,
  завершённый тест и итог. Разные гостевые браузерные контексты изолированы.
- Две одновременные отправки на один пропуск/вопрос сохраняют ровно один первый
  ответ. Тренировочное прохождение не переписывает статистику. Повторный тест
  создаёт новую попытку; лучший балл сохраняется даже при следующем результате 0%.
- TopicProgress вошедшего пользователя записывается в БД. Завершение требует
  всех действующих пропусков и лучшего теста не ниже настроенного порога.
- Подписки на предмет/всё, ACTIVE/PAST_DUE, границы grace period, ручной доступ,
  неверная область, будущий/истёкший период, отсутствующий/заблокированный/
  удалённый аккаунт покрыты unit-тестами. Интеграционно проверен живой AccessGrant
  и немедленный запрет ответов после его истечения.
- В HTML и React Flight закрытого урока отсутствуют маркер приватного абзаца,
  варианты пропусков, вопросы и объяснения. В серверном DTO — только два
  разрешённых блока без вариантов, нет теста/прогресса/списка пропусков.
- До ответа публичные данные не содержат correctOptionIds/correctId, explanation,
  gapKey и исходный синтаксис, указывающий правильный вариант. Тексты вариантов
  доступны для выбора; правильность среди них раскрывается только после ответа.
- Прямые запросы к gap answer, test start и test answer без права доступа дают 403.
  Чужой Origin, чужая попытка теста, поддельный вариант и устаревшая версия
  отклоняются. Снятая с публикации тема и черновик предмета дают 404.
- Markdown санируется, raw HTML и опасные URL не исполняются. Работают таблицы,
  callout-блоки и якоря на источник вопроса.
- Лимит запросов проверен на параллельных транзакциях: из двух запросов на
  последнем свободном месте проходит ровно один.
- Предыдущие сценарии входа, согласия, Telegram mock, роли редактора,
  автосохранения/конфликта и публикации остались зелёными в полном прогоне.

В первом прогоне E2E исправлен селектор вопроса: номер и текст входят в общий
доступный заголовок fieldset. После исправления полный прогон успешен. Правила
доступа и проверки ответов ради теста не ослаблялись.
