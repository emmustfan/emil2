# Задания с выбором и вводом ответа

Обновление по запросу пользователя от 7 ноября 2026. Работает в методичке и
в итоговом тесте. В методичке один ответ выбирается из списка прямо в предложении,
свободный ответ вводится там же; несколько ответов показываются чекбоксами.
В итоговом тесте варианты видны сразу. Ответ сохраняется после проверки.

## Три типа

- **Один правильный вариант** — выпадающий список в тексте методички;
  радиокнопки в итоговом тесте.
- **Несколько правильных вариантов** — чекбоксы. Верный результат требует
  всего правильного набора без лишних отметок. Частичных баллов нет.
- **Короткий ответ** — слово или короткая фраза. Автор задаёт эталон и допустимые
  формулировки. Проверка игнорирует регистр, пробелы по краям, повторные пробелы,
  различие «ё/е». Пунктуация и числовые разделители сохраняют значение: если
  нужны разные написания, добавьте их явно. Семантической проверки ИИ нет.

## Как составить вопрос теста

1. Откройте тему из кабинета администратора или из назначенного учителю предмета
   и форму «Новый вопрос».
2. Выберите тип задания и напишите текст вопроса.
3. Для выбора заполните варианты и отметьте правильный кружком либо несколько
   правильных чекбоксами. Для текста укажите эталон и, при необходимости,
   допустимые формулировки по одной на строке.
4. Добавьте объяснение и выберите связанный фрагмент методички.
5. Проверьте поведение в предпросмотре и нажмите «Сохранить вопрос».

Для вариантов теста сохранены границы 3–5; в множественном выборе отмечаются
не менее двух правильных. Для короткого ответа список вариантов отсутствует.

## Как добавить задание в методичку

Визуальный способ: выделите слово → «Пропуск» → заполните варианты →
«Сохранить пропуск». Для изменения выберите его цветную метку и снова нажмите
«Пропуск». Подробно — [создание урока](lesson-authoring.md).

Дополнительный конструктор ниже редактора также сохранён:

1. Раскройте «Добавить задание в методичку».
2. В тексте вокруг пропуска поставьте одну отметку `____`.
3. Выберите тип, заполните варианты либо эталон, добавьте объяснение.
4. Нажмите «Вставить задание». Конструктор сам добавит разметку в конец текста.
   При необходимости переместите этот абзац в редакторе.
5. В блоке «Задания в методичке» можно изменить тип, отметить дополнительные
   правильные варианты, добавить допустимые формулировки и объяснение. Нажмите
   «Сохранить настройки пропуска», затем сохраните черновик.

Существующий синтаксис `[[правильный|дистрактор|дистрактор]]` работает.
Текстовый пропуск записывается как `[[=эталон]]` без дистракторов.
Если после `=` есть разделитель `|`, сохраняется прежний формат выбора:
это поддерживает старые варианты, которые начинались с символа `=`.

Эталон и варианты существующего пропуска редактируются в тексте методички;
настройки проверки — в соответствующей раскрывающейся карточке.
Первый правильный вариант из разметки остаётся правильным и при множественном
выборе. Дополнительные правильные варианты можно отметить в настройках.

Ученику каждый пропуск пронумерован. Под содержащим его абзацем, списком или
таблицей показана карточка с ответами; номер в тексте ведёт к этой карточке.
Закрытый платный урок по-прежнему отдаёт только разрешённое превью без вариантов.

## Публикация и сохранение истории

Изменение заданий возвращает опубликованную тему в черновик и требует
повторной проверки/публикации. Невалидный набор правильных вариантов или
допустимых формулировок блокирует публикацию.

Первый ответ на пропуск сохраняется. «Пройти заново» очищает отображение
и позволяет тренироваться, сохраняя статистику первого ответа. Повторное
нажатие тоже очищает выбранные варианты и введённый текст.

У сохранённого ответа есть снимок выбранных/правильных значений и объяснения:
последующее изменение типа задания не переписывает старую обратную связь.
Изменение эталона или контекста может создать новую идентичность пропуска;
прежняя история остаётся у архивного задания. У теста сохраняются отдельные
попытки и лучший результат, попытка привязана к опубликованной версии темы.

## Проверка на Mac

После получения обновлённой папки проекта выполните:

```sh
bash start-mac.command
```

Скрипт применит новую миграцию с сохранением данных. В предмете
«Попробуйте платформу» появится дополнительная бесплатная тема
«Три типа ответа: попробуйте сами»:
http://localhost:3000/learn/platform-demo/answer-types.

Её seed добавляет только отсутствующую тему и не перезаписывает существующие
примеры, вопросы или результаты пользователя. Все примеры немедицинские.
