## Что проверяют тесты

- HMAC Telegram, неверные/изменённые/просроченные/будущие payload и replay.
- Полный серверный Telegram-вход на синтетической подписи и callback iframe:
  чужой источник игнорируется, корректный приводит к входу. Реальные запросы
  Telegram в тестах блокируются.
- Два параллельных подтверждения одной email-ссылки: проходит ровно одно.
- Истечение ссылки, browser nonce, подтверждение только POST, session cookie.
- Rolling лимиты по email/IP, cooldown, лимит сессий при параллельных входах,
  продление и истечение сессий, запрет blocked/deleted аккаунтам.
- Изменение почты только после подтверждения и только для инициирующего аккаунта;
  остальные сессии отзываются, конфликтующие аккаунты не сливаются.
- Реальная доставка SMTP в Mailpit через nodemailer.
- Согласие не предустановлено; без него нельзя попасть в профиль/кабинет.
  Новая версия требует повторного согласия, устаревшая версия отклоняется.
- Origin forgery отклоняется, роль USER получает 403, EDITOR/ADMIN допускаются.
- Сохранение профиля, перезагрузка и выход с отзывом сессии.

Чистая БД создавалась отдельно от `app`, после проверки удалена. Проверены
числа тарифов/тем/вопросов/пропусков и диагностических вопросов, роль seed-админа
без фиктивного подтверждения email, неизменность ID при повторном seed.
